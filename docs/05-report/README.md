# Báo cáo đồ án

Thư mục dành cho bản báo cáo. Nguồn tài liệu để dựng báo cáo:

| Chương báo cáo | Nguồn |
|---|---|
| Phân tích yêu cầu, actor, use case | `docs/01-requirements/requirements.md` (mục 1-3, 9) |
| Thiết kế dữ liệu | `docs/02-erd/erd.md` + mục 8 requirements |
| Thiết kế kiến trúc, lý do chọn | `docs/03-architecture/decisions.md`, `module-map.md` |
| Cài đặt, kiểm thử, CI/CD | `docs/04-team/progress.md`, `tests/`, `.github/workflows/ci.yml` |
| Rủi ro, hướng phát triển | mục 12-13 requirements, `review-notes.md` |
